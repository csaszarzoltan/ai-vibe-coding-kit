# Cursor Workflow Guide

My proven workflow for vibe coding with Cursor IDE.

## Setup

1. Install Cursor: https://cursor.sh
2. Configure models in Settings → Models:
   - Primary: Claude Opus 4.5
   - Fast: GPT-4.5
   - Budget: MiMo V2.5

## Daily Workflow

### Morning: Planning
1. Review yesterday's progress with Cursor Composer
2. Break down today's tasks into small, testable pieces
3. Write acceptance criteria for each piece

### Development Loop
1. **Cmd+K** - Inline editing (small changes)
2. **Cmd+L** - Chat for questions and explanations
3. **Composer** - Multi-file changes for larger refactors
4. **Agent mode** - Autonomous task execution

## Best Practices

- Always review AI suggestions before accepting
- Keep commits small and focused
- Use @-mentions to reference files
- Write clear commit messages
